## 📌 Projetos em destaque

### 🎫 HelpDesk — Sistema de Chamados

Sistema Full Stack para gerenciamento de chamados de suporte técnico.

**React + TypeScript + Axios + Java + Spring Boot + PostgreSQL**

Principais funcionalidades:

* Autenticação e autorização
* Perfis de Usuário e Técnico
* Criação e gerenciamento de chamados
* Controle de status e prioridade
* Técnico pode assumir chamados
* API REST
* JWT com cookie HttpOnly

🔗 [Frontend](https://github.com/patrickviniciusfs/helpdesk-web)

🔗 [Backend](https://github.com/patrickviniciusfs/helpdesk-api)
